时迁主控台 1.1.0 · 便携版（免安装）
============================================================

一、怎么开
------------------------------------------------------------
双击本文件夹里的  ①双击启动.bat

就这一步。不需要装 Python、不需要 pip、不需要联网。
浏览器会自动打开 http://127.0.0.1:5000 （没弹出来就手动复制这个地址）。

第一次启动约 3~6 秒。窗口里出现"地址：http://127.0.0.1:5000"就是成功了。
关掉那个黑窗口 = 关闭主控台。

二、为什么这个版本"谁都能打开"
------------------------------------------------------------
旧包只有源码，目标电脑必须自己装 Python 3.10+ 和 Flask，
少一样就闪退 —— 这就是在别的电脑上打不开的原因。

这个包把运行环境一起带来了：
  runtime\            内置 Python 3.14 + 全部依赖（100 MB 左右）
  时迁主控台_1.1.0\    界面本体（Flask 后端）
  shiqian_v9\         业务工程（语音 / 出票 / 核销）
  launcher.py         启动器（打印提示、开浏览器、拉起服务）
  时迁主控台UI完整开发文档与源码_1.1.0.docx

启动时一定用 runtime\python.exe，跟系统里装没装 Python 无关。
唯一例外：runtime 文件夹被删了，才会退回用系统 Python。

三、文件夹别拆开
------------------------------------------------------------
· 时迁主控台_1.1.0 和 shiqian_v9 必须同级
· 整个文件夹可以随便搬到 U 盘、桌面、D 盘，路径带中文也没关系
· 不要把 ①双击启动.bat 单独拖出来双击 —— 它靠"自己所在目录"找 runtime

四、解压这一步最容易出错
------------------------------------------------------------
压缩包约 50 MB，解开后 110 MB、上千个小文件。
· 用 7-Zip / Bandizip 解压最稳；Windows 自带解压请等进度条走完
· 解压后确认这三样都在：runtime\python.exe、时迁主控台_1.1.0\console_ui.py、shiqian_v9
· 只拖出来一部分文件会提示 "runtime\python.exe not found"

五、第一次用建议做的事
------------------------------------------------------------
1) 「系统概览」看四个模块状态
2) 「核销中心」核销一个码（码池里已有 100 个 6 位码）
3) 「系统设置」改机器人地址 / 端口（保存会自动备份 config.yaml）
4) API Key 和核销口令不在 config.yaml 里，存在 Windows 凭据管理器，
   页面上只显示 ********

六、打不开的时候按这个顺序查
------------------------------------------------------------
1) 双击后窗口一闪就没
   → 解压不完整或被杀毒拦了。先确认 runtime\python.exe 存在；
     再试：右键 ①双击启动.bat → 以管理员身份运行。
2) 想看真实报错
   → 在包目录按住 Shift + 右键 → "在此处打开 PowerShell/终端"，输入：
        runtime\python.exe launcher.py
     报错会完整留在窗口里。
3) 提示端口被占用
   → 改 时迁主控台_1.1.0\config.yaml 里 server.consoleport（比如 5001），重开。
4) 页面能开但模块显示未运行
   → 看「进程与日志」的报错。语音模块要麦克风；没有会自动转键盘/文字模式，
     不影响核销和配置。
5) 提示"Windows 已保护你的电脑"
   → 未签名程序，点"更多信息 → 仍要运行"。
6) 要给局域网平板看
   → 命令行先 set SHIQIAN_CONSOLE_HOST=0.0.0.0 再启动。
     开了等于同网段谁都能操作，只在可信内网这么做。

七、这个版本和"给开发机用的版本"有什么不同
------------------------------------------------------------
· 多了一个 runtime\ 文件夹（内置解释器和依赖），所以体积大
· 启动器改成 ASCII 批处理 + launcher.py 打印中文，
  避免中文批处理在某些 Windows 上被 cmd 拆错行
· 两边源码完全一致，改代码时改 时迁主控台_1.1.0\ 里的文件即可
