## 启动

- 推荐：根目录 `3_启动_时迁控制台.bat`
  （它会顺便把三个桥要用的 Python 指到 `Runtime_Python310`）

- 原版入口：`①双击启动.bat`（只开主控台，桥会去本机 conda 找解释器）

启动后浏览器自动开 `http://127.0.0.1:5000`。

## 主控台里有什么

| 页面 | 作用 |
|---|---|
| 概览 | 模块状态、进程、机器人连接 |
| 接待工作台 | 听（麦克风/VAD/ASR）→ 生成（Ollama qwen3:8b）→ 呈现/出票 |
| 机器人传感 | DDS 状态、29 关节、IMU、麦克风、相机、机器人播报 |
| 动作与光影 | 动作库（.g1motion / .csv），走 `motion_bridge.py` 回放 |
| 首次见面 | YuNet 人脸 + MediaPipe 人形 + 雷达 ping + 自动欢迎 |
| 系统设置 | 各桥端口、网卡、解释器、模型 |

根目录的 `3_启动_时迁控制台.bat` 会设置：

```

SHIQIAN_MOTION_DIR    = <包根>\GUI_3_Shiqian\时迁主控台_1.1.0\motions
```

所以换机后不需要再去「系统设置」里手工填 conda 路径。

## 这个副本里清掉了什么

| 清掉的东西 | 原因 |
|---|---|
| `shiqian_v9\data\segments\*.wav` | 现场测试录音，约 3 MB，留着只会让包变脏 |
| `shiqian_v9\data\mic_last.wav` | 同上 |
| `shiqian_v9\data\logs\` | 运行日志 |
| `*.lock` | 进程锁文件，换机后是垃圾 |
| `__pycache__` | 字节码缓存，Python 版本不同反而添乱 |

业务数据（`codes.csv`、`issued_tickets.csv`、`redeem_log.csv`）保留了。

## 注意

- 主控台用 `runtime\python.exe`（Python 3.14，embeddable）。
  它启用了隔离模式，**不要**往它的 `Lib\site-packages` 里塞包；
  桥需要的包都在 `Runtime_Python310` 里。
- 相机流来自机器人机载电脑 `.164:8081`，本包不包含那个 mjpeg_server；
  机器人不在线时「机器人传感」页会显示视频未连接，这是正常的。
- 麦克风/播报会真的操作机器人 voice 服务（mode 1↔2），停止时会还原。
