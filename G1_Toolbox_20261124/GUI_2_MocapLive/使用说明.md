# GUI 2 · 实时转换（MocapLive）

这是原来的 `D:\DATAWORK\G1\MocapLive`，原样搬进来。完整功能说明看同目录的 `README.md`，
这里只写「在这个便携包里怎么用」。

## 一句话

SlimeVR（VMC/UDP）→ 14 点人体帧 → GMR IK → 29 关节 → 限幅/看门狗 → MuJoCo 仿真 / G1 真机。

## 启动

- 双击根目录 `2_启动_实时转换.bat`
- 或本文件夹 `启动_实时转换.bat`
- 或 `自检.bat`（不接硬件，先验证 GMR/关节顺序/IK 耗时）

## 三种玩法

| 场景 | 怎么选 |
|---|---|
| 没硬件，先看效果 | 源选「合成动作（无硬件）」，输出选「MuJoCo 仿真」 |
| 接 SlimeVR | 源选「SlimeVR (VMC/UDP)」，端口 39539；SlimeVR 里 Port Out=39539、Address=127.0.0.1、勾 Enable |
| 上真机 | 输出选「DDS 真机」，网卡选 192.168.123.x 那块；先「仿真」验证方向 |

## 这个包替你把路径指好了

启动 bat 会设置：

```
G1_DEVKIT = <包根>\Shared\G1_DevKit
```

`mocap_live/paths.py` 会从这里找：

- GMR：`Shared\G1_DevKit\05_retarget\GMR`
- MuJoCo 模型：`Shared\G1_DevKit\03_models\menagerie\mujoco_menagerie\unitree_g1`

所以**不要单独把 GUI_2 文件夹拖走**；要移动就整个包一起移。

## 配置

- `configs\default.yaml`：默认（仿真、5 点、1.75m、原地模式）
- `configs\g1_real.yaml`：真机参数（DDS + 29DOF rev1.0）
- `configs\ik\slimevr_pos_to_g1.json`：SlimeVR 专用 IK 表（四肢纯位置）
- GUI 里改完可以「保存配置」覆盖当前文件

## 录制的数据

- 默认 `records\`（本包已建空目录）
- 录出来是 36 列 / 60Hz 的 CSV，可以直接丢给管道转换 GUI 的「训练」页

## 真机安全

「机器人」页的按钮走官方 RPC，不是仿真：

- 释放运控 / 阻尼 / 零力矩 → 机器人立刻变软，**必须吊挂**
- 站起类动作前方留 1 米
- 第一次上真机，先把 `ramp_s` 留着 2.5 秒，别改成 0
