一、这个包是什么
----------------------------------------------------------------------
把本机改过的三套程序、它们用到的库/模型/样例，以及一个能直接跑的
Python 运行环境，全部装进这一个文件夹。目标：换台 Windows 电脑，
解压后双击就能开，不需要装 Python、不需要 pip、不需要联网。

  1) 管道转换 GUI   离线 BVH -> 重定向 -> G1 动作（.g1motion / CSV）
  2) 实时转换 GUI   SlimeVR 惯性动捕 -> GMR IK -> MuJoCo / G1 真机
  3) 时迁控制台     网页控制台（门票/接待/语音）+ 机器人桥
                    （传感器 / 动作模组 / 视觉三个桥 + 机载相机流）

三个 GUI 都放在根目录同一级（GUI_1 / GUI_2 / GUI_3），没有互相嵌套。
根目录只有：说明、5 个 bat、3 个 GUI 文件夹、Shared、Runtime、Env。


二、【必须先看】解压路径只能用英文
----------------------------------------------------------------------
MuJoCo（实时转换的仿真内核）在 Windows 上打不开带中文的路径。
所以：

    解压到  D:\G1_Toolbox_20261124                        ✔ 正确
    解压到  C:\Users\33823\Desktop\G1_Toolbox_20261124    ✔ 可以（用户名英文）
    解压到  D:\工具\G1_Toolbox_20261124                    ✘ 不行（路径有「工具」）
    放在「桌面\新建文件夹」里                              ✘ 不行

包里面的运行目录已经全部改成英文（GUI_1_Pipeline / Shared / Runtime_Python310…），
就是为了避开这个坑。你只需要保证「解压到的那一层」也没有中文。
时迁控制台自己的中文文件夹名不影响（它不用 MuJoCo）。

另外：解压目录别太深。包里有 3.5 万个文件，最长路径约 217 字符（从 D:\ 算），
Windows 默认 260 字符上限。建议就放 D:\G1_Toolbox_20261124，不要套三层以上。


三、怎么开（认准这五个 bat）
----------------------------------------------------------------------
  0_环境自检.bat          先跑这个，全绿再往下
  1_启动_管道转换.bat     离线管道（BVH 转 G1 动作）
  2_启动_实时转换.bat     实时动捕（SlimeVR -> G1）
  3_启动_时迁控制台.bat   网页控制台（会自动开浏览器）
  4_安装依赖_备用.bat     换机/环境坏了才用（pip 脚本）

也可以进 GUI_x 文件夹里双击「启动_xxx.bat」，效果一样。
第一次启动稍慢（PySide6 / MuJoCo 要加载 3~8 秒），之后正常。
关掉黑色命令行窗口 = 关闭程序。

五、三个程序各自要注意什么
----------------------------------------------------------------------
【1 管道转换】GUI_1_Pipeline
  · 输入：BVH（任何标准人形骨架；ChingMu 的 Hips/Spine3 命名也能认）
  · 输出：右侧「导出」可存 .g1motion / CSV / NPZ；也能同步到时迁动作库
  · 默认导出目录：GUI_1_Pipeline\output（不存在会自动建）
  · 「训练」页是独立训练作业，需要 Isaac Lab；本包不带 Isaac（见第十节）
  · 依赖：unitree_sdk2py（已装进 Runtime，并加进 PYTHONPATH）

【2 实时转换】GUI_2_MocapLive
  · 数据源三选一：SlimeVR(VMC/UDP 39539) / 回放 / 合成动作
  · 输出三选一：MuJoCo 仿真 / DDS 真机 / 不输出
  · 启动前先在 SlimeVR 里设 Port Out=39539、Address=127.0.0.1、勾 Enable
  · 「机器人」页走官方 RPC：释放运控 / 阻尼 / 零力矩 / 站起 / 坐下
  · 真机前必须吊挂！释放运控 = 机器人立刻失去平衡
  · 它通过 G1_DEVKIT 环境变量找 GMR 和 MuJoCo 模型，启动 bat 已经指好

【3 时迁控制台】GUI_3_Shiqian
  · 主控台本体用自带 runtime（Python 3.14），不需要外部 Python
  · 「机器人传感 / 动作 / 视觉」三个桥用 Runtime_Python310（已自动指好）
  · 端口：5000 主控台 / 5001 核销 / 5002 mock / 5011 传感 / 5012 动作 / 5013 视觉
  · 大模型默认 Ollama qwen3:8b（127.0.0.1:11434），没起会走兜底模板
  · 机器人默认 IP：192.168.123.161（本体）、.164（机载电脑/相机）
  · 相机流：http://192.168.123.164:8081/stream（机载 mjpeg_server）
  · 包里保留了它自己的 ①双击启动.bat；用根目录的 3_启动 才会自动带上桥的解释器

八、换机 / 环境坏了怎么办
----------------------------------------------------------------------
  先跑 0_环境自检.bat 看哪一项红。
  · 如果 Runtime_Python310 被删了/被杀毒拆了：
      装一个 Python 3.10~3.12，然后双击 4_安装依赖_备用.bat
      它会用 pip 按 Env\requirements_*.txt 装齐（需要联网）
  · 如果只是少了某个包，也可以手动：
      python -m pip install -r Env\requirements_mocap.txt
  · 时迁控制台自带 runtime，不受影响；它的三个桥需要 Runtime_Python310，
    没有的话会退回本机 conda（如果装了）。

十一、安全提醒（真机必读）
----------------------------------------------------------------------
  · 任何「释放运控 / 阻尼 / 零力矩 / 站起」之前，必须吊挂或有人扶稳，
    周围 2 米内不要站人。
  · 实时转换第一次上真机，先在 GUI 里用「仿真」验证关节方向和限位，
    再把输出切到 DDS。
  · 时迁动作桥的 policy 模式默认关闭（motion.allow_policy=false），
    不要在没验证的情况下打开。


十二、这次打包做了哪些「改动」（只动路径，不动业务逻辑）
----------------------------------------------------------------------
  · 三套程序原样复制；业务逻辑没有改，只加了两处路径兜底：
    1) `pipeline/train/trainctl.py` 的 ISAAC_PY 允许用同名环境变量覆盖
       （原机器写死 D:\isaac\venv\Scripts\python.exe，换机后训练页会找不到）；
    2) `mocap_live/paths.py` 在没设 G1_DEVKIT 时，会按文件位置自动找
       `<包根>\Shared\G1_DevKit`，最后才回退到原开发机路径。
  · 新增：启动 bat、Env\check_env.py、Env\pip_install.py、各说明文档。
  · 运行环境的 unitree_sdk2py 从「可编辑安装（指向 D:\DATAWORK\G1）」
    改成「直接装进 site-packages」，否则换机后 import 会指回原机器。
  · 时迁的测试录音、__pycache__、.lock 文件、conda-meta 没有带。
