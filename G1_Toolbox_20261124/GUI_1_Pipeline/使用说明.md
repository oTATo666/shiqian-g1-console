# GUI 1 · 管道转换（离线 BVH → G1 动作）

这是原来的 `D:\DATAWORK\G1\pipeline`，原样搬进来，只改了启动方式（不再依赖本机 conda）。

## 它是干什么的

把一段人形 BVH 动作，离线重定向成 Unitree G1（29 DOF）的关节轨迹，然后：

- 在 3D 里预览「人骨架 → 机器人骨架」的对应关系
- 导成 `.g1motion`（时迁动作库格式）、`.csv`（训练用 36 列 / 60Hz）、`.npz`
- 或者直接 DDS 下发到真机回放（`rt/lowcmd`，需要网卡在 192.168.123.x）

## 启动

双击本文件夹里的 `启动_管道转换.bat`，或根目录的 `1_启动_管道转换.bat`。

## 界面怎么用（最短路径）

1. 「打开 BVH」选一个 `.bvh`（本包 `Shared\samples\bvh-recording.bvh` 可以试）
2. 预设选 `P5`（胸 + 左右大腿 + 左右小腿），骨架命名不同也没关系，解析器有别名表
3. 看左侧人骨架是否跟手；右侧 G1 是否同步（第一次加载约 2~4 秒）
4. 「重定向」页调 One Euro 滤波 / 输出帧率（50/100/200）
5. 「输出」组：
   - `💾 保存动作模组` → `.g1motion`（推荐，时迁直接能读）
   - `导出 CSV` → 训练用（36 列，60Hz）
   - 导出后如果检测到本包里的时迁动作库，会问你要不要同步过去
6. 真机回放前，先确认「仿真」里方向/限位都对，再切到 DDS

## 「训练」页

训练页本身能打开、能建作业、能看历史曲线，但**真正开训需要 Isaac Lab**：

- 原机器在 `D:\isaac`（约 9 GB），本包没有带
- `pipeline\train\trainctl.py` 里默认写死 `D:\isaac\venv\Scripts\python.exe`
- 换机器想训练：装好 Isaac Lab 后，把 `ISAAC_PY` 环境变量指过去即可
  （`set ISAAC_PY=D:\isaac\venv\Scripts\python.exe`）

不训练不影响其它所有功能。

## 注意

- BVH 里的骨架命名不统一（Hips / HIP / LeftUpLeg…），解析器已经做了大小写归一和别名；
  如果某个关节一直对不上，先看日志里 `discover_rig` 的匹配结果。
- 真机回放会走 `MotionSwitcher` 释放运控，**必须吊挂**。
