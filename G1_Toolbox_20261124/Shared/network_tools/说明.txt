G1 网络与连接工具（便携版，任何 Windows 10/11 电脑可用）
==========================================================

双击运行（会自动弹 UAC 请求管理员权限）：

  一键连接机器人.bat
      自动找到插着网线的网卡 → 设为 192.168.123.222/24（不设网关）
      → 扫描 192.168.123.0~254 → 报告机器人是否在线

  恢复自动获取IP.bat
      把这块网卡改回 DHCP（之后拿它接路由器上网用）

命令行可选参数（直接调 ps1）：
  -Manual                          有多块网卡时手动选
  -IP 192.168.123.10               换一个本机地址（避免和同网段其他电脑冲突）
  -Gateway 192.168.123.1           额外设置网关（G1 直连不需要，通常留空）
  -Restore                         等价于"恢复自动获取IP"
  -DryRun                          只检测不改配置

判断标准
  - 192.168.123.161  运动控制主控   <- 必须在，SDK 全靠它
  - 192.168.123.164  开发计算单元   <- 机器人的机载电脑（SSH/HTTP）
  - 192.168.123.222  本机

常见故障
  1) 只看到 164，没有 161
     说明机器人本体没上电（或运控板还没启动）。按机器人电源键开机，
     等 30 秒再重跑本脚本。机载电脑 164 可能由独立供电先起来，
     所以"164 通、161 不通"是典型的本体未上电。
  2) 网段里一个设备都没有
     网线没插在机器人网口 / 网口灯不亮 / 网线坏。
  3) 有 IP 但 SDK 读不到数据
     多半是开了 Clash / SSTAP 之类的 TAP 虚拟网卡抢路由，
     先退出代理软件再试。

注意：本次改动只影响选中的那块网卡，不动无线网卡，也不影响上网。
