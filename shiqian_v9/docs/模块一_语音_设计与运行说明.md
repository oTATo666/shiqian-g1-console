# 模块一 · 语音 ASR / TTS —— 设计与运行说明（v9）

> 对应代码：`modules/voice/`（8 个文件）+ `modules/secret_source.py` + `modules/logging_utils.py`
> `main.py` 直接 `from modules.voice import VoiceEngine`（v9 清理时已移除兼容层）。
> 测试：`tests/test_voice_filter.py` / `test_voice_gate.py` / `test_voice_asr.py` / `test_voice_tts.py` / `test_policy_no_secrets.py`
> 本文只讲**这一模块**；模块二/三/四的设计在各自文档里。

## 一、要解决的四个真实问题

| # | 现场问题 | 以前会怎样 | 现在怎么处理 |
| :-- | :--- | :--- | :--- |
| 1 | 机器人播报时麦克风还开着 | 把自己的播报识别成观众的下一句话，形成"自己跟自己聊天"的死循环 | **半双工门闸**：播报先叫停收音，且必须等它退出（最多 2 秒）才出声；再加一层**回声守卫**兜住缓冲残留 |
| 2 | 教室里一堆"嗯、啊、半句话" | 垃圾文本全喂给大模型，白等 3 秒还污染记忆点 | **过滤器**：空/纯标点/语气词/过短/低置信度全部拦下，并明确提示"请再说一遍" |
| 3 | 两个人抢着说 | 你一句我一句拼成一句乱码 | **会话锁**：一次只处理一个人，第二个人直接得到"请稍等" |
| 4 | 现场断网 | Edge-TTS 合成失败 → 全场静音 | **固定话术提前缓存**（播本地文件不需要网）+ 断网回退**离线系统语音** + 最后只显示文字 |

## 二、一次收音的完整时序

```
                    ┌──────────── 会话锁（一次只处理一个人）────────────┐
观众走近            │                                                  │
  │                 ▼                                                  │
  ├─ ptt_mode=vad ──► 直接开麦                                          │
  └─ ptt_mode=enter ► 等回车（StdinTrigger）                            │
                    │                                                  │
                    ▼                                                  │
        ┌──── 门闸 begin_listen()：播报中就等，等到超时就让路（BUSY）────┐
        │                                                              │
        ▼                                                              │
   录音（wait 8s / 单句最长 15s，可被 cancel 打断）                      │
        │                                                              │
        ├─ 被打断（播报插进来）──────────► CANCELLED（丢弃，不提示重说） │
        ▼                                                              │
   识别链  Vosk ──失败/空──► 云端 ASR ──失败/超时──► （空）              │
        │                                                              │
        ▼                                                              │
   过滤：空 → 纯标点 → 语气词 → 过短 → 低置信度 → 回声 → 截断            │
        │                                                              │
        ├─ 可重试类（空/过短/低置信度/回声）                             │
        │     └─► 播报"没听清，请再说一遍"（占用"说"的令牌，天然与收音互斥）│
        │           └─► 下一轮（最多 max_rounds 轮）                    │
        ▼                                                              │
   仍失败 ──► 键盘兜底（同一套过滤器）──► 返回 ListenResult              │
                    └──────────────────────────────────────────────────┘
```

**关键点**：重录前的提示语是**真的播出来**的，而播报本身会占住"说"的令牌，所以下一轮收音一定会等它念完 —— 不需要额外写"播完再听"的调度逻辑，互斥关系天然成立。

## 三、接口清单

### 3.1 `VoiceEngine`（唯一对外门面）

```python
VoiceEngine(asr_cfg, tts_cfg, secrets, voice_cfg, *,
            secret_source=None, recorder=None, asr_backends=None,
            tts_backends=None, cache=None, player=None,
            logger=None, indicator=None, trigger=None, inline_tts=False)
```

| 方法 | 返回 | 说明 |
| :--- | :--- | :--- |
| `listen_once(rounds=None)` | `ListenResult` | 听一句话。**不抛异常**，失败用 `reason` 表达 |
| `listen_and_transcribe()` | `str` | 兼容旧接口，只要文本 |
| `speak(text, blocking=True)` | `SpeakResult` | 播报。`blocking=False` 进队列立即返回 |
| `speak_async(text)` | `SpeakResult` | 同 `speak(blocking=False)` |
| `prewarm_fixed_phrases()` | `dict` | 预热固定话术，返回 `{warmed, skipped, failed}` |
| `preflight()` | `dict` | 打印并返回能力清单（麦克风/识别链/合成链/密钥/缓存/门闸） |
| `status()` | `dict` | 运行期快照（门闸/会话/缓存/计数） |
| `shutdown(timeout=5)` | `None` | 念完队列再退出 |

### 3.2 `ListenResult`

```python
ListenResult(text, reason, backend, confidence, raw_length, elapsed_ms)
# reason ∈ ok / no_speech / empty / too_short / low_confidence / echo / busy / cancelled / error
# .ok / .retryable / .prompt()  -> 直接拿给界面用
```

`prompt()` 直接给出现场提示语，主程序不需要再写一串 if：

```python
r = voice.listen_once()
if r.ok:
    use(r.text)
else:
    print("🙉 " + r.prompt())      # "没听清，请再说一遍。"
```

### 3.3 配置项（`config.yaml` 的 `voice:` 段）

| 键 | 默认 | 作用 |
| :--- | :--- | :--- |
| `ptt_mode` | `vad` | `vad` 自动听 / `enter` 按回车说话 |
| `show_indicator` | `true` | 屏幕上显示"🎙️ 正在聆听"（真终端会转圈） |
| `max_rounds` | `2` | 听不清最多重录几轮 |
| `retry_prompt` | 没听清，请再说一遍。 | 重录前真的念出来 |
| `trigger_timeout` | `30` | 按键模式下等回车最多几秒 |
| `gate.speak_drain_timeout` | `2.0` | 播报前最多等收音退出几秒 |
| `filter.min_chars / max_chars` | `2 / 40` | 过短判负、过长截断（按有效字符计） |
| `filter.min_confidence` | `0.55` | Vosk 平均词置信度门槛 |
| `filter.echo_window_seconds` | `25` | 播报后多久内的相似句判为回声 |
| `tts.synth_timeout` | `6.0` | 单次合成的硬超时 |
| `tts.offline_fallback` | `true` | 断网回退系统语音 |
| `tts.fixed_phrases` | 6 条 | 启动时预热的话术（字典，按 key 取） |
| `asr.cloud_asr_connect_timeout / cloud_asr_timeout` | `3 / 8` | 云端识别两段式超时 |

## 五、降级矩阵（任何一格都能演）

| 环节 | 一级 | 二级 | 三级 | 兜底（一定可用） |
| :--- | :--- | :--- | :--- | :--- |
| 收音 | 麦克风 + VAD | 麦克风 + 按回车 | — | 键盘输入（同一套过滤） |
| 识别 | 本地 Vosk（离线） | 云端 ASR（3s 连接 / 8s 读取超时） | — | 键盘输入 |
| 合成 | 缓存命中（零延迟、不联网） | Edge-TTS（6s 超时） | 离线 SAPI（pyttsx3） | 只显示文字 |
| 播放 | pygame | Windows MCI | — | 只显示文字 |
| 密钥 | 环境变量 | 系统凭据库（keyring） | — | 不用云端，纯本地 |

**每一格的失败都只降级，不抛异常、不阻塞。** 这是本模块最重要的约束 —— 现场可以"效果差一点"，但绝不能"卡住不动"。

## 七、现场怎么用

### 7.1 第一次准备

```bat
:: 装依赖
1_点我安装环境_Windows.bat

:: 云端识别密钥（只在需要云端兜底时配；不配就走本地 Vosk + 键盘）
setx SHIQIAN_ASR_KEY sk-你的密钥
:: 或者存进系统凭据库（更稳，只有本机本用户能读）
python -c "import keyring;keyring.set_password('shiqian-g1','asr_key','sk-你的密钥')"

:: 本地离线识别模型（可选，但强烈建议：断网就靠它）
:: 下载 vosk-model-small-cn-0.22 解压到 models\ 下
```

> **任何情况下都不要把密钥写进 `config.yaml`。** 配置里只能出现变量名（`asr.key_env`），不能出现值。

### 7.2 启动

```bat
2_点我启动系统_Windows.bat          :: 自动模式：有麦就用麦，没有就打字
2_点我启动系统_Windows.bat --keyboard   :: 强制键盘（教室不方便说话）
2_点我启动系统_Windows.bat --no-tts     :: 不发声，只显示文字
2_点我启动系统_Windows.bat --health     :: 只体检，不进主循环（排障首选）
```

启动时会先打一份能力清单，`✅`/`⚠️` 一眼看出哪一环没就绪：

```
[语音自检] ⚠️ 麦克风(keyboard　未安装 SpeechRecognition / PyAudio)
           ⚠️ 识别·vosk：未安装 vosk
           ✅ 合成·edge：就绪（zh-CN-XiaoxiaoNeural，超时 6.0s）
           ✅ 合成·offline：就绪（系统语音引擎）
           ⚠️ 云端ASR密钥：未配置
[语音预热] 新合成 6 条 / 已有缓存 0 条 / 失败 0 条
```

### 7.3 两种收音方式

- **自动（默认 `ptt_mode: vad`）**：观众走近直接说，说完停 1 秒自动结束。
- **按键说话（`ptt_mode: enter`）**：按回车开始说，说完再按回车。嘈杂展台更稳，也不会收到路人闲聊。
  额外约定：以 `/` 开头的一行是"直接打字当输入"（`/我想拍照`），其它行仍是命令（`admin` / `exit` / `status`）。

### 7.4 断网怎么办

1. 启动时预热的 6 条固定话术**照播**（播本地 mp3，不需要网）；
2. 新生成的记忆点：Edge-TTS 失败 → 自动转系统语音（音色一般但听得清）；
3. 识别：本地 Vosk 正常；没有模型就转键盘。全程不卡、不报错。

### 7.5 日志看哪里

`data/logs/session.log`，一行一条 JSON。**只有指标，没有观众原话**：

```json
{"ts":"2026-11-13 20:31:07","kind":"asr_result","reason":"ok","backend":"vosk","chars":7,"confidence":0.91,"elapsed_ms":640}
{"ts":"2026-11-13 20:31:08","kind":"tts","chars":19,"cached":true}
```

`chars` 是字数、`confidence` 是置信度、`cached` 是否命中缓存 —— 够定位问题，又不留隐私。

## 八、与旧版（v5）的行为差异

| 项 | v5 | v9 |
| :--- | :--- | :--- |
| 播报与收音 | 各干各的，靠"尽量错开" | 门闸硬互斥 + 回声守卫 |
| 识别质量 | 识别到什么就用什么 | 过空/过短/低置信度/回声四道关 |
| 断网播报 | 静音（只有文字） | 缓存话术 + 离线系统语音 |
| 密钥 | 从加密保险箱取（固定种子派生，源码可见即可解） | 只从环境变量/系统凭据库取，**不使用固定种子** |
| 日志 | 会把识别文本写进日志 | 只写长度+哈希，永不写原话 |
| 音频缓存文件名 | md5(文本) | sha256(音色+语速+文本)，文件名不含原文 |
| 对外接口 | `listen_and_transcribe()` | `listen_once()`（保留旧接口） |

## 九、已知限制（写清楚，不藏）

1. **底层录音无法被"立刻"中断**：`speech_recognition` 的 `listen()` 是阻塞调用。门闸的取消标记只能让它在**本轮结束时**放弃结果，所以最长会多录一段时间（由 `speak_drain_timeout` 兜住，超时照样播）。真正的即时打断需要换 `sounddevice` 流式采集，属于后续优化项。
2. **云端 ASR 不给置信度**，所以云端路径只做字数过滤，不做置信度过滤（Vosk 才给词级 conf）。
3. **离线语音音色一般**（系统 SAPI），只用于断网回退，不作为日常音色。
4. **按键说话只认回车**，不支持"按住空格"：Windows 上低级键盘钩子会和命令行输入抢 stdin，风险大于收益（详见 `trigger.py` 文件头注释）。
5. `data/tts_cache/` 里的音频是**观众可能听到的公开话术**，不含隐私；但记忆点会出现在小票语音里，所以缓存目录不要外传（模块四会一并说明数据目录的边界）。
